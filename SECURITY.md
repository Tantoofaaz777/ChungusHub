# Security policy

ChungusHub is self-hosted. An install holds its owner's API keys, chat history and
password hash, and it can be opened to a local network, so a flaw here costs somebody
real credit and real privacy. Reports are welcome and taken seriously.

## Reporting a vulnerability

**Please do not open a public issue.** Open a private advisory instead, from the
fork's [Security tab](https://github.com/Tantoofaaz777/ChungusHub/security/advisories/new), if private reporting is available.
It reaches the maintainer and nobody else.

This fork has no published alternative private contact. Do not post sensitive details in a
public channel. If the issue also affects the original ChungusHub, follow the
[upstream security policy](https://github.com/patcireamo/ChungusHub/blob/main/SECURITY.md).

A report is easiest to act on with three things in it: what an attacker gains, the steps
to reproduce it, and the version from Settings → About.
